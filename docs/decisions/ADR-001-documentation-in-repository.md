# ADR-001: Documentation in the Repository

## Status

Accepted

## Context

Argos requires its product intent, scope, and architectural decisions to evolve with the implementation and remain reviewable alongside it.

## Decision

Maintain project documentation and architecture decision records as versioned Markdown in the relevant source repository. Material decisions will be recorded before or with the changes they govern.

## Consequences

Documentation changes receive the same review history as implementation changes. Contributors must keep documents current, while repository history provides traceability for evolving decisions.
